# Amazon Price Tracker

## Description
A Python-based Amazon Price Tracker that monitors product prices and alerts users when prices change.

## Features
- Open Amazon product pages using Selenium
- Extract product title using BeautifulSoup
- Extract current product price
- Store price history in CSV
- Detect price increases and decreases

## Technologies Used
- Python
- Selenium
- BeautifulSoup
- Pandas
- WebDriver Manager

## How to Run
1. Install dependencies from requirements.txt
2. Run app.py
3. Enter an Amazon product URL
4. View price and alerts

## Future Scope
- Email notifications
- Multiple product tracking
- Price trend graphs
